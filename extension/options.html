How to use

    
    
      
  1. Open a NetSuite dashboard (Home or any center tab) and click Dashboard Manager at the bottom right.
    2. 
      
  2. Export to file captures layout, portlets and every portlet's settings into a .nsdash.json file you can send to a colleague.
    3. 
      
  3. The colleague opens their own dashboard, picks the file in the Import tab, previews the plan and clicks Apply. A backup of their previous dashboard is stored here first.
    4. 
      
  4. Administrators can also generate an SDF publisheddashboard object or use NetSuite's native Publish Dashboard to push to whole roles.
